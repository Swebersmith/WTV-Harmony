1概述

本政策说明 映屿VIdeo鸿蒙应用（以下简称“WTV”或“本应用”）如何访问、使用、保存和保护信息。WTV 由 Swebersmith（以下称“开发者”）提供。

WTV 的核心功能是：根据您输入的片名或链接，向您配置的搜索接口/默认站点请求搜索结果；在您选择影片后，请求详情、解析或媒体地址，并使用系统原生播放器播放。WTV 不要求注册账号，不建立用户画像，不投放广告，不接入第三方统计 SDK。

本政策仅适用于 WTV 应用本身。您在应用内访问的第三方站点、解析服务、媒体源和投屏接收端由其运营者独立处理数据，适用其各自的隐私政策。

2我们处理的信息

2.1 保存在本机的信息

  • 接口配置：站点地址、搜索接口、解析接口、接口名称、启用状态，以及您填写的接口令牌（如有）。
  • 片单与记录：收藏、观看记录、上次播放进度、最近搜索词。
  • 播放设置：后台播放、自动小窗、自动连播、HLS 去插播、减少动效、主题/外观等。
  • 诊断日志：播放步骤、上次退出原因、系统提供的崩溃/冻屏摘要与堆栈。

上述信息保存在应用私有目录，不会自动上传到开发者服务器。您可以在应用内清空观看记录、搜索历史或诊断日志，也可以卸载应用删除全部本机数据。

2.2 网络请求

当您搜索、打开详情、解析或播放时，WTV 会向以下对象发送必要请求：

  • 您在「接口设置」中配置的搜索、解析、站点同步接口；
  • 默认站点 https://wtv.webber.qzz.io（用于默认搜索/配置同步）；
  • 您选择播放的媒体地址、网页播放线路，以及可选的预处理服务。

这些请求可能包含您输入的搜索词、影片/剧集地址、接口令牌（如有），以及常规网络信息（IP 地址、User-Agent、请求时间）。对应站点可能按常规服务器日志记录这些信息，具体以其隐私政策为准。

2.3 剪贴板

只有在您主动点击「粘贴」按钮时，WTV 才读取剪贴板文本，用于填入视频链接；不会在后台读取、轮询或上传剪贴板内容。

2.4 分享、投屏与系统能力

  • 系统分享：您点击「分享」时，WTV 调用系统分享面板，把当前视频链接交给系统及您选择的目标应用。
  • 投屏：您选择投屏设备后，WTV 通过系统投播能力把当前媒体地址发送给您选择的接收端；接收端可能记录该地址和网络信息。
  • 画中画 / 后台播放 / 系统播控：由鸿蒙系统提供，WTV 仅向系统注册媒体会话和播放状态，不借此收集您的个人信息。

2.5 诊断日志

诊断日志仅保存在本机，不自动上传。您可以在「应用版本 → 错误与播放日志」导出 TXT、复制或清空。导出前应用会遮盖 HTTP(S) 链接和常见 token / password / Authorization 字段；系统日志仍可能包含设备运行信息，请在分享前自行检查。

2.6 我们不会主动收集

WTV 不申请也不读取您的通讯录、短信、精确位置、相册、相机、麦克风或已安装应用列表；不收集广告标识符；不进行跨应用追踪。

3系统权限

权限用途
ohos.permission.INTERNET搜索、详情、解析、媒体播放、站点同步。
ohos.permission.GET_NETWORK_INFO显示网络状态，在网络切换时给出提示。
ohos.permission.KEEP_BACKGROUND_RUNNING后台音频播放、系统媒体任务与画中画。

WTV 不申请相机、麦克风、通讯录、定位、相册或文件读取权限。

4共享与第三方

除以下情形外，开发者不会向第三方共享您的信息：

  • 您主动使用系统分享或投屏；
  • 您配置的第三方站点在提供搜索、解析或播放服务时自行接收请求；
  • 法律法规要求，或有权机关依法要求。

WTV 不向第三方出售数据，不接入广告 SDK、统计 SDK 或推送 SDK。应用使用的开源组件（如 libmpv、FFmpeg、OHCodec 等）仅在设备本地运行，不构成数据共享；许可信息见仓库的 THIRD_PARTY_NOTICES.md。

5存储、保留与删除

  • 存储位置：应用私有目录；不进行云同步。
  • 保留期限：本机数据保留到您主动清空或卸载应用；诊断日志按容量轮换，最多保留有限份数。
  • 删除方式：在应用内删除单条记录/收藏、清空观看记录、清空搜索历史、清空日志；卸载应用会删除全部本机数据。
  • 开发者服务器：WTV 不上传片单、观看记录、搜索历史或诊断日志到开发者服务器；默认站点仅按普通网络请求处理搜索/配置请求，可能保留常规服务器日志。

6您的权利

在适用法律允许的范围内，您对与本应用相关的信息享有以下权利：

  • 访问与更正：在应用「片单」「接口设置」「应用版本」中查看和修改本机保存的信息。
  • 删除：删除单条收藏/记录、清空观看记录、清空搜索历史、清空诊断日志，或卸载应用。
  • 撤回同意：关闭后台播放、自动小窗、投屏等可选功能；停止使用相应功能即停止相关处理。
  • 咨询与投诉：通过下方联系方式与开发者联系。

如果您配置的第三方站点保存了您的请求信息，请直接联系该站点的运营者行使权利；开发者无法删除第三方站点独立保存的数据。

7安全

WTV 采用应用私有目录保存本机数据，并遵循最小权限原则，仅申请实现功能所必需的权限。互联网传输受相应站点采用的 HTTPS 等机制保护；但任何网络传输都无法保证绝对安全，请避免在不可信网络中填写敏感接口令牌。

诊断日志在导出前会遮盖常见敏感字段，但仍可能包含设备运行信息。请仅在信任的环境下分享日志。

8未成年人

WTV 不面向未成年人单独设计，也不主动收集未成年人个人信息。未成年人应在监护人指导下使用本应用；如监护人发现未成年人向第三方站点提交了信息，请联系相应站点处理。

9政策变更

开发者可能因功能、法规或系统能力变化更新本政策，并在本页面标注新的“最后更新”日期。重大变更会在生效前通过应用内提示或发布页面等合理方式告知。继续使用本应用即表示您接受更新后的政策。
